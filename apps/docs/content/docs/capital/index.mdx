# Capital

Capital is a financial management platform purpose-built for international freelancers and contractors — with a sharp focus on Brazilian tech professionals earning in foreign currencies (USD, EUR, GBP).

It unifies business finance, personal finance, investment portfolio tracking, multi-currency management, and Brazilian tax/bank integration in a single application.

## Tech Stack

- **Framework:** Next.js (App Router), React 19
- **API:** Hono
- **Database:** PostgreSQL with Prisma 6
- **Styling:** Tailwind CSS 4, Radix UI, shadcn-style components
- **State:** Zustand
- **i18n:** next-intl (Portuguese / English)
- **AI:** Anthropic SDK for transaction categorization

## Key Features

- Multi-entity financial management (PJ business + PF personal)
- Multi-currency engine (BRL, USD, EUR, GBP) with automatic exchange rates
- Investment portfolio tracking (B3 stocks, FIIs, Tesouro Direto, CDBs)
- Budget management with credit card installment awareness
- Bank statement import (Nubank, XP CSV/OFX)
- AI-powered transaction categorization
- Recurring transaction management
- Brazilian tax helpers (Carnê-Leão, IR preparation)
