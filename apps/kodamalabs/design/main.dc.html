Capital

A private finance workspace. It keeps my money and my companies’ money in one ledger: accounts, cards, investments, several currencies. An assistant reads statements from PDFs and screenshots and proposes how to book them.

About 1,870 tests. The October 2026 move to a single ledger took 2,305 lines of migration SQL, rehearsed on a production dump after a 705-line read-only precheck.

Must not happen. A statement written to the books without anyone approving it.

The assistant can read a statement. It cannot import one on its own.

Its import plan stays a proposal until I click Confirm import, and that confirmation expires after 30 minutes. Every write to the books can be undone, whoever made it.

The cost. No import ever finishes by itself. Each plan waits for me.

Not taken. Commit first, review later.

Sentinel

Sentinel joins Brazil’s public procurement, company, sanction and election records in one database, and flags prices and relationships for a person to review.

7 public sources and 6 analysis engines. Claude reads the tender documents themselves. 24,627 tenders ingested (snapshot, May 2026).

Must not happen. An alert that reads as an accusation.

For prices, statistics propose. An evaluator decides, and its default is to suppress.

The evaluator is a language model. If its key is missing, its call fails or its reply cannot be parsed, no price alert is published. The wording rule: a point to check, never an accusation. When I tightened it, a migration deleted 241 model-written alerts so they would be regenerated.

The cost. It stays quiet about things that may be real, and I have not yet measured how often.

Not taken. Publishing every price the statistics flag.

Cosmos

A production line for software, staffed by coding agents, running on my own machine. I describe a line in YAML: stations in order, each a typed contract with a worker assigned to it. One objective goes in, each station hands its output to the next inside the item’s own git worktree, and a draft pull request comes out.

Started on 7 October 2026: about 13,900 lines of TypeScript, 271 tests passing in CI, and a validator with 44 checks that reads a line before any model is called. The engine refuses 48 programs and 15 git subcommands whatever a worker’s list says. On my monorepo it has opened three draft pull requests; none is merged yet.

Must not happen. An agent doing something nobody gave it the authority to do.

Workers don’t ask permission. They have an authority, and the rest is refused.

A command outside a worker’s list is refused with the reason, and the worker adapts or escalates with a question. A delivery counts only when the station’s checks pass. The engine, not the model, computes the diff and opens the pull request, always as a draft. The line stops for me in three cases: a check the line asked for, an escalation, an external action it was not authorized to take.

The cost. A command I forgot to list stops the whole line until I answer. And it is a policy, not a sandbox: an allowed command still runs with my permissions.

Not taken. A permission prompt for every command.

In development since 7 October 2026 · command line only · private repository, one user: me

If you can’t articulate the riskiest assumption in one sentence, the idea isn’t ready.

How I build it and keep it running.

I write incidents down with their root cause. I rehearse risky migrations on a production dump. I turn each convention into a test.

With coding agents

Agents write most first drafts. I set the plan, the data model and the rules, and I answer for what runs. They work in parallel git worktrees and have opened 64 of the 85 pull requests so far. A written contract comes first, then a local gate of lint, typecheck and tests, then my merge. What is missing: a CI server and a second reviewer.
